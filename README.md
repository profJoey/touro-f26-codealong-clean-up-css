# Codealong 9 — Clean Up Your CSS

Starter page for Week 9. It works, but the CSS is messy on purpose.

- `index.html`: the Brightside page
- `style.css`: the starter. Edit this one.
- `solution.css`: the finished version (instructor reference)

## Planted problems

| Problem | Where | Code-along step |
|---|---|---|
| Four slightly different blues (`#1d4ed8`, `#1e4fd8`, `#1d4fd9`, `#1c4ed7`) | header, `.button`, `a`, `.feature h3` | 1–3 |
| Random spacing (7, 9, 11, 12, 13, 14, 15, 17, 18, 19, 21, 22, 23, 25px) | throughout | 4–5 |
| Tagline `#a3a3a3` on white (~2.5:1) | `.tagline` | 6–7 |
| Footer `#b0b0b0` on white (~2.2:1) | `.site-footer` | bonus: let students find it with Lighthouse |
| `outline: none` on links and buttons | `a, .button` | 8–9 |
| Hero image has no `alt` | `index.html` | 10 |
| `h1` → `h3` skips a level | feature headings | 10 |

## CodePen

Paste `index.html` (body contents only) into the HTML panel and `style.css` into the CSS panel. Lighthouse won't run inside the CodePen editor: use **Change View → Full Page** or the debug view (`cdpn.io/pen/debug/...`) and run Lighthouse on that tab.
